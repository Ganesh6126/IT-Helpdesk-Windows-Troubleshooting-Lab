IT Helpdesk and Windows Troubleshooting Lab

 Project Overview
This project simulates the responsibilities of an IT Helpdesk Support Technician. It focuses on Windows system inspection, network troubleshooting, issue documentation, ticket management and Excel reporting.

 Tools and Technologies
- Windows 11
- Task Manager
- Device Manager
- System Information
- Command Prompt
- Microsoft Excel
- GitHub

Practical Exercises
1. Task Manager Analysis
2. Device Manager Inspection
3. System Information Analysis
4. Network Diagnostics using CMD
5. IT Helpdesk Network Troubleshooting Simulation
6. Excel Ticket Tracker and Dashboard
7. PivotTables and PivotCharts

 Key Skills Demonstrated
- Windows troubleshooting fundamentals
- Network connectivity diagnostics
- IP configuration and DNS resolution
- Helpdesk ticket documentation
- Excel formulas and data analysis
- PivotTables and PivotCharts
- Basic IT support reporting

Project Outcome
Created a simulated helpdesk ticket management system with an Excel dashboard to monitor ticket status, priority and category.

Disclaimer
This is an educational simulation using sample helpdesk tickets and personal Windows troubleshooting exercises.
