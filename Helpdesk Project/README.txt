# IT Helpdesk and Windows Troubleshooting Lab

Project Overview
A practical IT support simulation designed to understand Windows troubleshooting, basic network diagnostics, helpdesk ticket management, and Excel-based reporting.

Objectives
- Understand Windows system performance.
- Inspect hardware and device drivers.
- Identify basic network connectivity issues.
- Perform network diagnostics using Command Prompt.
- Simulate IT helpdesk ticket handling.
- Create an Excel ticket tracker and dashboard.

Tools Used
- Windows 11
- Task Manager
- Device Manager
- System Information
- Command Prompt
- Microsoft Excel
- GitHub

Practical Exercises
1. Task Manager Analysis
2. Device Manager Inspection
3. System Information Analysis
4. Network Diagnostics
5. Helpdesk Network Troubleshooting Simulation
6. Excel Ticket Tracker and Formula Dashboard
7. PivotTables and PivotCharts

Key Learning Outcomes
- Basic Windows troubleshooting.
- IP configuration and DNS diagnostics.
- Network connectivity testing using ping and nslookup.
- Helpdesk ticket documentation.
- Excel formulas, PivotTables, and PivotCharts.
- IT support reporting and issue tracking.

Project Status
Completed foundational Windows troubleshooting and helpdesk reporting exercises. Additional simulated ticket scenarios are being developed.
